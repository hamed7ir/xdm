# Screenshots

The main README shows one image from this folder:

```
screenshots/xdm-on-windows-rt.png
```

**Drop the screenshot in here under exactly that name** and it will appear at the top of the
front page. Until then the README shows the alt text instead.

Suggested: XDM's main window on the device, PNG, roughly 1000–1400 px wide. The README renders it
at 720 px, so anything wider than that is only useful for people who click through.

This folder is deliberately separate from `docs/`, which is upstream's project website and is not
touched by this fork.
